# v0.8.7 星云分类与显示维护

2026-10-10：扩展常见学科方向，并让星云只在当前视图中有内容时显示。

## 行为

- 预设二级分类从 3 类学科扩展到 33 类，共 185 个方向，覆盖理科、工程、外语、人文、经管、医学等。
- 原有其他大学学科和用户自定义分类仍可展示，不限制为这 33 类。
- 一级星云与展开后的二级星云只从当前显示节点的已保存分类生成。
- “待细分”和“未归类”只在有对应节点时显示。搜索或切换学科后，无内容的分类不继续显示。
- 共享节点关联的多个星云仍保留；移出当前视图的节点和星云只清理显示对象，不删除本地资产。
- “语法”“阅读理解”等跨语言共用名称不单凭方向名推断为英语；有明确父级时保持对应语言。
- 修复切换范围时旧星云标签残留，重新生成本地组件；上游源码和模型资源未修改。

## 修改文件

- `src/knowledge_taxonomy.py`：补充学科方向，避免共用方向错误归属。
- `src/knowledge_graph_service.py`：仅生成当前有内容的一级、二级分组。
- `scripts/build_starmap_component.py` 与 `src/components/knowledge_starmap/index.html`：前端隐藏空分组，清理移出视图的显示对象。
- `pages/20_知识串联.py`：显示规则说明。
- `tests/test_knowledge_taxonomy.py`：分类保存、共享来源、空视图及搜索后范围切换回归。
- `README.md`、`README_EN.md`、`README_JP.md`：同步 v0.8.7 的分类与显示范围。
