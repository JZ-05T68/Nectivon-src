# v0.8.7 全平台文字框语音输入按钮

2026-10-10：按用户最新要求，在现有文字输入框右端增加点击听写按钮。

## 行为与范围

- 首页和全部 21 个页面使用现有 `render_workspace` 安装同一套静态脚本。
- 原生文字框、长文本、筛选搜索、展开区、动态表单，以及同源嵌入的标注、截图说明和星图文字控件由同一入口处理。
- 用户点击后才调用浏览器 `SpeechRecognition` / `webkitSpeechRecognition`，允许麦克风后开始听写；再次点击结束。
- 只将最终结果插入当前光标位置或替换当前选中文字；保留其余文字、字数限制和听写期间的手工修改。
- 识别不触发 Enter、提问、表单提交或资料保存。结果同步到原控件后，仍由用户修改、提交或保存。
- 密钥框（包括切换到明文显示）、禁用/只读控件、数字等非文字控件不启用听写。折叠区展开后自动补齐按钮，关闭或移除正在听写的控件时中止识别。
- 一次仅识别一个框；切换框时中止旧识别，忽略延迟回调。单次听写最多 60 秒，再留 5 秒结束宽限。
- 权限拒绝、设备或服务故障、浏览器不支持时显示中文提示，保留原稿及普通文字输入。

## 数据与依赖

不改数据库，不新增后端语音 API、模型、密钥、录音存储、付费 AI 调用或第三方脚本依赖。
浏览器语音服务是可选增强，可能将音频发送至其识别服务，并可能要求联网；识别语言沿用控件语言或浏览器语言。
原有系统输入法听写、离线功能和手动修改保留。仅加载仓库随附静态 JS/CSS，不将用户文本拼入可执行 HTML。
使用已声明支持的 Streamlit >=1.59.1 的 `st.html(..., unsafe_allow_javascript=True)`。

参考：[MDN SpeechRecognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition)、
[Streamlit st.html](https://docs.streamlit.io/develop/api-reference/text/st.html)。
