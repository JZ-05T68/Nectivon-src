# 知识星图：分步连接与断开

更新时间：2026-10-14。适用于本机 8501 的「知识串联」。

## 操作步骤

1. 开启手势，用食指停留选中第一颗知识点星。
2. 连接时比 👍，断开时比 ✌️。检测成功后，星图提示已锁定第一颗星。
3. 松开手势，用食指停留选中第二颗知识点星，重复第一步使用的关系手势。
4. 两颗星选择完成后，在星图下方点击「确认连接」或「确认断开」；点击「取消」放弃。

无需同时选中两颗星。第一颗星的标题与操作提示持续显示，途中可点击「取消这次操作」。
关系手势、导航手势和捏合触发语音的识别规则保持原有定义。

## 行为与边界

- 起点在第一次手势成功后单独保存，不再依赖上一颗选中的星。
- 每次关系手势需要连续 4 帧稳定，保留原有冷却，并要求松开后再次比手势。
- 稳定检测期间改变选中的星会重新计帧；同一颗星、不同操作手势和非知识点星不会提交。
- 关闭手势、取消操作或星图数据变化会清除未完成的起点。
- 手势连接和断开都等待页面确认；语音与打字连接仍按原有流程处理。
- 摄像头画面与识别模型在本机处理，用户资料和本地数据库不进入源码同步。
