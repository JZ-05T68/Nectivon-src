# v0.8.7 星图控件与关系手势修复

2026-10-13，调整知识串联页面的控件布局，并补齐关系手势到本地持久化的处理链路。

- 七项手势说明合成星图下方的一排；窄屏可横向滚动。
- 底部依次为手势开关、说话按钮、语音状态反馈，整组居中，紧贴说明行下方。
- 朗读和手势语音选项保留在星图右上角。
- 星图渲染、选星光标和摄像头使用实际页脚高度避让，控件不会遮盖彼此。
- 拇指朝上连接两颗知识点星，二指张开请求断开；断开确认区位于星图下方，未确认时保留关系。
- 语音或打字也可使用“连接 A 和 B”“断开 A 和 B”，支持派生、依赖、支持、矛盾和实例关系。

连接与断开前需要依次选中两颗不同的知识点星。重复选中同一颗星不会丢失上一颗星。

关系手势原先把单手关键点传给需要手列表的 OK 检测函数，造成帧回调异常。现在传入完整手列表，关系手势优先于握拳处理，避免误打开详情；双手缩放继续保留。异常会显示中文恢复提示，连接和待确认断开都有状态反馈。

控件仍由本地构建脚本生成，手势模型保留本地资源，组件通过 Streamlit 事件把关系请求交回 SQLite 服务。应用启动和离线功能不依赖外部 AI。

验证命令：

```powershell
python -m ruff check .
python -m pytest tests/test_knowledge_graph.py tests/test_voice_input_compatibility.py tests/test_knowledge_taxonomy.py
git diff --check
```

相关测试包含组件重建一致性、真实手势检测与事件桥接、握拳冲突、双手隔离、关系保存、幂等连接，以及断开确认和取消。

实际摄像头操作仍需要在用户设备上审核；自动化验证使用合成关键点和临时数据库。
