# v0.8.7 source maintenance notes

Source update date: 2026-10-10.

This update publishes the current v0.8.7 source and synchronizes the Chinese,
English, and Japanese READMEs. It does not create a tag, release, installer, or
deployment. The latest formal GitHub release at the time of this update remains
v0.8.6. Personal-use maintenance prioritizes stability, trustworthy materials,
and changes with a limited scope.

## Included scope

- Local knowledge connections, subject clouds and subfields, source links,
  optional knowledge-mining drafts, and mathematical reading of knowledge points.
- Optional graph gestures and browser speech control, with typing as a fallback.
- Saved foreign-language subject names and local routing into layer one only.
  Explanations use sources, questions, answers, and actual reasoning; correct
  answers also require evidence of understanding. There is no extra review or
  new language-specific workflow.
- A composition-Enter fix in the graph command input; native text fields and
  editing remain in place, without a new platform speech-recognition service.
- Related regression tests and corrections to test database isolation.

The star-vault source, resources, and adapted graph are included after the user
explicitly confirmed public-distribution rights on 2026-10-10. Existing upstream
notices are retained. This records the authorization without inventing an
additional open-source license grant. The public provenance manifest replaces
the machine-specific desktop path with a descriptive source label; source-file
hashes remain unchanged.
Git attributes preserve the upstream and generated component bytes across
checkouts. Whitespace checks skip the immutable upstream snapshot and generated
HTML/model bundles; authored Python, documentation, and integration scripts
remain checked normally.

## Public source boundaries

User documents, page images, databases, backups, logs, runtime state, real `.env`
files, keys, internal audit captures, and installer outputs are excluded.
School, undergraduate-major, and catalog-source JSON files are also excluded
because their redistribution basis is unconfirmed. Tests requiring these inputs
need separately authorized data; their local results do not prove that the same
tests run without those inputs.

Browser text entry, editing, saving, and composition behavior were checked with
isolated synthetic materials. Real microphone dictation across devices and
live-model foreign-language explanations remain unverified. Browser speech
recognition can require network access; it is optional and typing remains
available. Mathematical typesetting should be checked against the retained
original text. The earlier full test run also reported one existing
Starlette/httpx deprecation warning; dependencies were not changed for it.
